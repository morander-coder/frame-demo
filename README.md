# FRAME Demo 0.1

Real iPhone camera + FRAME v1.18 interface.

Real: camera permission, rear-camera live preview, still capture, PWA install shell, settings/profile persistence.
Simulated: scene analysis, recommendations, camera exposure control, AI.

Camera access on iPhone requires HTTPS. Publish this folder to an HTTPS host (for example GitHub Pages), open it in Safari, allow camera access, and use Share → Add to Home Screen.
